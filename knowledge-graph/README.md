# Knowledge Graph (Neo4j)

This directory contains the schema and sample data for the Neo4j Knowledge Graph.

The graph represents entities like Customers, Orders, Products, and Suppliers, and the multi-agent decisions associated with them.
Currently, this is a **starter implementation**.

## Files
- `schema.cypher`: Constraints and structure.
- `sample_data.cypher`: Starter mock data (ORD-1042, WP-800).
